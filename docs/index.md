# flickr-autotagger

AI-powered Flickr photo tagger using CLIP zero-shot classification.

## Features

- 🔐 **Flickr OAuth** — Authenticate and sync all your photos
- 📥 **Resumable Downloads** — Incremental, concurrent image downloads
- 🤖 **Local AI Tagging** — CLIP zero-shot classification, no cloud APIs
- 🏷️ **Smart Tags** — 200+ default tags across 13 categories
- ✅ **Review & Approve** — Interactive tag review before pushing
- 🔄 **Push to Flickr** — Merge or replace tags on your Flickr photos
- 📤 **Export** — JSON, CSV, or XMP sidecar for Lightroom/Darktable
- 💾 **SQLite State** — Everything is resumable and incremental
